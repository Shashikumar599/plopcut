# plopcut brag video — plan

**What:** CapCut's web editor (its own UI and 36 MB C++/WASM engine), reverse engineered with REA and
running on localhost as "plopcut", with our own export, sound effects, stickers, stock video and
transitions plugged in. Then the honest twist: it's only the client.

**Angle:** hype-bait ("software is dead, everything is free") → real wall (HTTP 451) → it actually works
(aura) → the server is the product → plopcut becomes **flopcut**.

**Format:** 1080×1080, 30 fps, 30.0 s. No voiceover. Tone: chaotic hook → cinematic demo → deadpan close.

**Look:** dark (#07090d) with hex-dump texture, huge condensed white type (Anton), cyan #00c1cd accent
(plopcut / editor teal), red #ff3b3b for the wall. Thumbnails from brag/source behind the hook lines.
